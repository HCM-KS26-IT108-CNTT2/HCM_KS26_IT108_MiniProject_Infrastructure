# Green Tech
**Bước 1:**
- Mở powershell và sau đó dùng lệnh cd để trỏ tới thư mục đã lưu dự án

**Bước 2:**
- Sử dụng lệnh **Get-childitem .** để kiểm tra xem mình đã đứng đúng vị trí thư mục chưa.

**Bước 3:**
- Sau khi kiểm tra nếu đã đứng đúng thư mục thì sử dụng đường dẫn .\auto_report.ps1 để bắt đầu chạy script

**Bước 4:**
- Sau khi script chạy thành công không lỗi thì vào thư mục backup và kiểm tra file bao-cao-su-co.txt xem đã in lỗi vào thành công chưa
